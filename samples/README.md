# Real Hindi audio samples

Drop real recorded Hindi grievance clips here (`.wav` preferred, 16kHz mono).

These are the test fixtures for the conversation loop — not clean typed text:

- `opening_clean.wav` — a clear, one-shot grievance with most slots present
- `noisy.wav` — background noise / street audio
- `accent_rambling.wav` — accented, rambling, off-topic filler
- `correction.wav` — citizen states location, then corrects it mid-turn
- `incomplete.wav` — sparse utterance, forces follow-up questions

Sample content ideas (Hindi): water supply issue, broken streetlight/road,
electricity outage, with name/contact/date sprinkled or omitted depending on
which scenario each file targets.
